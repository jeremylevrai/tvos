# TV OS

TV OS est un accueil pour Android TV, avec une télécommande sur téléphone ou tablette et un compagnon Windows pour ton PC.

## Ce qu'il fait
- Un bureau TV simple, lisible de loin, pensé pour être facile à piloter.
- Une télécommande dans le navigateur de ton téléphone, associée avec un code affiché sur la TV.
- Le compagnon Windows : diffusion de l'écran du PC sur la TV, envoi de fichiers, notifications du PC (nom de l'application et titre seulement) et installation de TV OS depuis l'ordinateur.

## Téléchargements
Dernière version : 0.21.1
- TV-OS-Setup-0.21.1.exe : installateur du compagnon Windows 10 / 11.
- TV-OS-0.18.6.apk : application TV OS pour Android TV (Android 8.0 ou plus).
